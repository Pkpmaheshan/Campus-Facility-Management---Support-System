# Campus Facility Management & Support System (CFMSS)

A smart campus management system developed using Flutter, Laravel, and MySQL to improve campus facility management and administrative operations.

---

## 🚀 Features

- Facility issue reporting
- Reminder management
- Lecturer search
- Lost & found services
- Student management
- Lecturer management
- Academic management
- Batch management

---

## 🛠️ Technologies Used

- Flutter
- Laravel
- PHP
- MySQL
- XAMPP

---

## ⚙️ Installation

### Backend

cd campus_backend

composer install

php artisan serve

### Frontend

cd campus_app_n

flutter pub get

flutter run
